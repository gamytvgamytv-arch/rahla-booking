# سهل وبسيط — GitHub Ready — Reviewed Edition

هذه نسخة Frontend تجريبية محسّنة تجمع عناصر منصة الاستشارات الطبية والنفسية مع العناصر التعليمية الواردة في الملف السابق: الأخصائيون، الأسئلة، المرافق، الصيدليات، السوق الطبي، الأكاديمية، المجتمع، المقالات، المكتبة، الاختبارات، لوحة المستخدم والإدارة.

## تشغيل على الكمبيوتر
لا تحتاج هذه النسخة إلى Node.js أو npm.

يمكنك فتح `index.html` مباشرة، أو تشغيل خادم محلي بسيط:

```bash
python3 -m http.server 8000
```

ثم افتح:

`http://localhost:8000`

## رفع إلى GitHub
1. أنشئ مستودعاً جديداً.
2. ارفع الملفات الموجودة في هذا المجلد.
3. من Settings → Pages اختر النشر من فرع `main` والمجلد `/root`.
4. انتظر إنشاء الموقع.

## الملفات
- `index.html` — نقطة تشغيل الموقع.
- `app.js` — الصفحات، التنقل، اللغات، البحث والتفاعلات التجريبية.
- `styles.css` — التصميم المتجاوب.
- `supabase/schema.sql` — مخطط أولي لقاعدة البيانات.
- `DEPLOYMENT_AR.md` — خطوات النشر والربط.
- `REVIEW_REPORT_AR.md` — تقرير مراجعة الأخطاء والاختبارات.

## ما تم اختباره
تم إجراء 4 جولات مراجعة:
- JavaScript syntax.
- HTML/CSS structure.
- جميع مسارات SPA الرئيسية.
- التفاعلات الأساسية والبحث واللغة والفلاتر والنماذج.

## قبل الاستخدام الحقيقي
هذه نسخة Prototype. الدفع، Authentication الحقيقي، RLS، التخزين الخاص، KYC، الفيديو، الخرائط والتتبع الحي، المحافظ والتسويات، البريد/واتساب، AI والدردشة الخاصة تحتاج Backend ومزودات خارجية.

لا تضع مفاتيح API السرية أو مفاتيح الدفع داخل `app.js` أو GitHub.

الأرقام والأسماء والمحتوى الموجود في الواجهة تجريبي ويجب استبداله ببيانات حقيقية ومحتوى تملك المنصة حقوق استخدامه.
