# سهلة وبسيطة | منصة الاستشارات الطبية

منصة Flask عربية لعرض المؤسسات الطبية، الأسئلة والإجابات، الاستشارات، الشكاوى، الإشعارات، ولوحة المالك.

## التشغيل المحلي

```bash
python -m pip install -r requirements.txt
python app.py
```

ثم افتح `http://localhost:8000/`.

## تشغيل الإنتاج

```bash
gunicorn --bind 0.0.0.0:$PORT app:app
```

## متغيرات البيئة

```text
SECRET_KEY=غيّر-هذه-القيمة-في-الإنتاج
ADMIN_EMAIL=بريد-المالك
DATABASE_PATH=medical.db
```

## تنبيه

الحسابات والمقالات الافتراضية المعروضة لأغراض تجربة الواجهة فقط، وليست أخصائيين أو مؤسسات حقيقية. يجب ربط قاعدة بيانات دائمة، بوابة دفع، مزود فيديو، ومراجعة قانونية وطبية قبل الاستخدام العام.
